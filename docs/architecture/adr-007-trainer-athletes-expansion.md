## Structural change

Count production `.ts` files under `apps/api/src/modules/trainer-athletes/`, excluding `test/`. Physical lines include comments and interior blank lines. The module went from 16 files and 1,495 lines to 20 files and 1,616 lines (+121, 8.1%). The four inner files account for 87 lines: 47 in the pure invitation policy and 40 in three application contract files. Those inner files have one type-only inward import and no framework or database imports.

`TrainerAthletesService` went from 347 to 323 lines, `TrainerAthletesRepository` from 262 to 324, and the transaction service from 166 to 175. The exercise copy service stayed at 141 lines. The service now uses a Prisma type import for the existing read filter and performs zero direct Prisma error-code checks. The repository owns operation-specific `P2002` and `P2025` translation. Termination gives the facade an explicit changed-state outcome and carries the existing success projection through a generic result.
